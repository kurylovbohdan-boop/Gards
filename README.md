# GARDS prototype — запуск

    npm install
    npm run dev        (в PowerShell: npm.cmd run dev)

Открыть http://localhost:3000

## Откуда данные
- `lib/productsData.js` — товары (название, цена, ссылка, фото) взяты со страниц категорий gards.lv 28.10.2026.
  Фото грузятся прямо с gards.lv; в продакшене лучше хранить свои копии (CDN).
  ДЕМО остаются: остатки по магазинам и привязка товаров к рыбе/условиям (`fit`) — заменить данными магазина и проверить рыболовом.
- `public/fish/<pike|zander|perch|catfish>.jpg` — свои фото рыб (приоритет). Нет файла — берётся Wikimedia Commons, иначе рисунок-заглушка.
- `lib/dictionary.js` — все тексты LV/RU/EN. Юр. тексты (legal.*) и реквизиты ([указать]) заполнить и утвердить у юриста.
